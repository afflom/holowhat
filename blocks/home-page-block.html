Playground

The collaborative web toolkit

Build and publish directly in the browser - an infinitely editable development environment, built with web components and designed to be local-first (no account required).

It's all about blocks - these are the artifacts you create in Playground. Each tool in the environment is a block, the code editor, api client, local-first database, even the world canvas itself. Since blocks are themselves web components, use them in your favorite frontend framework, or directly in HTML.

Own your tools - influenced by the Smalltalk language, the source code for Playground is modifiable at runtime. Develop your tools in the same language that you create blocks: HTML, CSS and JavaScript. The world canvas below is themed like middle-earth. What world would you create?
